# Machyon on Discord

The **Machyon Community** on Discord is opening soon: a place to ask questions, share run reports and talk about
what Machyon should do next.

Until it opens:

- **Something isn't working?** The [troubleshooting guide](troubleshooting/index.md) and the
  [failure reasons](reference/failure-reasons.md) cover most problems, and `machyon doctor` checks one URL in detail.
- **Found a bug or have an idea?** Open an issue on
  [GitHub](https://github.com/DivyanshuSingh96/machyon/issues).
- **Want to know when it opens?** Follow [Divyanshu Singh on X](https://x.com/DivyanshuBuilds).
