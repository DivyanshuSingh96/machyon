# Licence and citation

## Machyon

Machyon is released under the MIT licence.

```text
--8<-- "LICENSE"
```

Opa and the Machyon wordmark are the project's brand. Using them to refer to Machyon is welcome;
[the guidelines are short](meet-opa.md#using-opa).

## Citing Machyon

If Machyon helps your research, please cite it. The repository's `CITATION.cff` is read by GitHub ("Cite this
repository"), Zenodo and most reference managers.

```bibtex
@software{singh_machyon_2026,
  author  = {Singh, Divyanshu},
  title   = {Machyon: fast, self-tuning, loss-free bulk image downloading},
  version = {1.0.0},
  year    = {2026},
  url     = {{ "{" }}{{ config.extra.repo }}{{ "}" }},
  license = {MIT}
}
```
