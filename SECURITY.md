# Security policy

## Supported versions

Security fixes are released for the latest version of Machyon.

## Reporting a vulnerability

Please **don't open a public issue** for a security problem. Report it privately through GitHub:
[Security → Report a vulnerability](https://github.com/DivyanshuSingh96/machyon/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. You'll get a reply within a week, and
credit in the release notes once a fix is out, unless you'd rather stay anonymous.

Machyon writes files named from its input, follows redirects and verifies TLS, so reports about path handling,
certificate verification or resource exhaustion are especially welcome.
